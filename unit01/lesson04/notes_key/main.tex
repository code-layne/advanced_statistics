\begin{vocabbox}
\small
Fill in each term \textbf{as we name it} in the notes below.
\par
\termans{Unimodal, bimodal, uniform}{one main peak; two clear peaks; all bars about equal, with no peak at all.}
\par
\termans{Symmetric}{the left half of the distribution is roughly a mirror image of the right half.}
\par
\termans{Outlier}{a value that sits unusually far from the rest of the data --- investigated, never simply deleted.}
\par
\termans{Gap and cluster}{a gap is a stretch where nothing was observed; a cluster is a bunch of values set off by a gap.}
\par
\termans{Skewed right, skewed left}{named for the side the longer tail runs out on --- right: a few values much larger; left: a few much smaller.}
\par

\ans{pile} up. The \textbf{variability}, or \textbf{spread}, is how far the values reach
\ans{from each other}. Next lesson puts numbers on both; today we describe them by eye.

% ── ROW 3: unusual features and the four-part description ────────────────────
\mainidea[Unusual]{Features} &
An \textbf{outlier} is a value that sits unusually far \ans{from} the rest of the data.
A \textbf{gap} is a stretch of the number line where \ans{nothing} was observed. A
\textbf{cluster} is a group of values bunched together and set off from the rest by a
\ans{gap}.

\vspace{4pt}
\fcolorbox{navy}{sky}{\parbox{\dimexpr\linewidth-2\fboxsep-2\fboxrule\relax}{\centering
\textbf{Four things or nothing --- \ans{SOCS}:} \textbf{S}hape $\cdot$ \textbf{O}utliers and
other unusual features $\cdot$ \textbf{C}enter $\cdot$ \textbf{S}pread\par
--- every one of the four stated \ans{in context}, naming the variable and its units.}}

\vspace{3pt}
\textbf{In context} means a stranger could use the sentence.

% ── ROW 4: the tail decides — THE CRUX ───────────────────────────────────────
\mainidea[Skewed which way?]{The Tail} &
Count Picture I's homes. Below \$400{,}000: $6 + 14 + 10 = $ \ans{30} of the 40. Above
\$600{,}000: \ans{2} of the 40 --- yet the picture stretches past \$700{,}000, because
two houses really did sell for that. The pile is on the \ans{left}; the long thin tail runs
to the \ans{right}. So Picture I is \textbf{skewed right}: piled \emph{left}, named \emph{right}.

\vspace{4pt}
\fcolorbox{navy}{sky}{\parbox{\dimexpr\linewidth-2\fboxsep-2\fboxrule\relax}{\centering
\textbf{The name of a skew follows the \ans{tail}, not the \ans{pile}.}\par
Skewed \textbf{right}: the longer tail runs right, so most values are \ans{small} and a few
are much larger. Skewed \textbf{left}: the longer tail runs \ans{left}.}}
\\
& \textbf{All four for Picture I:} sale prices are \ans{skewed right} and unimodal; no gaps, and
\ans{two} homes above \$600{,}000; the middle home sold for about \$\ans{300{,}000}; prices
run from about \$100{,}000 to \$\ans{800{,}000}.
