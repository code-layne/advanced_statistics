% ── ROW 1: discrete vs continuous ────────────────────────────────────────────
\mainidea[Discrete \&]{Continuous} &
A \textbf{discrete} variable takes a \blank{1.9cm} number of values --- you can list them, and
nothing sits between two neighbours. A \textbf{continuous} variable can take \blank{2.0cm} value
in an interval: between any two values there is always \blank{2.6cm}.

\vspace{3pt}
\textbf{The test:} ask about the \blank{1.8cm}, not the digits written down.
\emph{Could a better instrument have split that value?}
\notesprompt{Classify each variable as discrete (D) or continuous (C).}

% ── ROW 3: histograms ────────────────────────────────────────────────────────
\mainidea{Histograms} &
Twenty-four dots is readable; two hundred would not be. So we \textbf{group}.

\vspace{3pt}
\stepnum{1}\ Choose an \blank{2.6cm} and mark the intervals on a number line.\par
\stepnum{2}\ \blank{1.4cm} the values that fall in each interval.\par
\stepnum{3}\ Draw one bar per interval; its \blank{1.4cm} is the count. The bars \blank{1.3cm}.
